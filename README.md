## Recursos
- chave secreta digitada apenas no site e salva localmente no aparelho;
- carregamento dos eventos com ID direto da planilha;
- alteração de data, título, horário e data final para todos;
- adição e exclusão de eventos para todos;
- cores e emojis globais;
- cores de gráficos globais;
- fallback para a planilha publicada sem chave.

## Primeiro uso
1. Abra Configurações.
2. Digite a NOVA chave secreta do Apps Script.
3. Clique em “Conectar e sincronizar”.
4. Use os botões “Salvar para todos os dispositivos”.
