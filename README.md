# V26 — MED070 A3 integrado

Calendário Medicina UFMG — 6º Período — 2026/2.

A versão V26 adiciona a disciplina MED070 — Conferências de Ética e Bioética para a subturma A3, com todas as avaliações, períodos, prazos, pontuações, locais, orientações de preparação e pontos de atenção.

Os eventos com período definido aparecem em todos os dias do intervalo. A integração é preservada mesmo após a sincronização remota do calendário.

A exportação ICS do site usa lembretes de 5 dias e 2 dias.
